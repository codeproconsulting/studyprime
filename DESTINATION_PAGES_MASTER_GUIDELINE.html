Study Prime Architecture Directive

Destination Pages Master Guidelines

Official Developer & AI Agent specification for URL naming conventions, ultra-premium UI rules, 301 server redirects, and technical SEO integration.

1. URL Architecture & Slug Convention (Strict Rule)

Every destination landing page on Study Prime MUST use the /destinations/study-in-[country] URL slug structure under the destinations parent route.

Country Required Canonical URL Remix Flat Route File Path
France https://studyprime.pk/destinations/study-in-france app/routes/destinations.study-in-france.tsx
New Zealand https://studyprime.pk/destinations/study-in-new-zealand app/routes/destinations.study-in-new-zealand.tsx
Hungary https://studyprime.pk/destinations/study-in-hungary app/routes/destinations.study-in-hungary.tsx
UK https://studyprime.pk/destinations/study-in-uk app/routes/destinations.study-in-uk.tsx
Canada https://studyprime.pk/destinations/study-in-canada app/routes/destinations.study-in-canada.tsx
❌ What NOT to do:
  • Never create root slugs like /study-in-france.
  • Never leave old duplicate indexable URLs (e.g. /destinations/france).

2. Server 301 Permanent Redirects

In app/routes/destinations.$country.tsx, the loader must permanently 301 redirect legacy country slugs to the new dedicated route:

// File: app/routes/destinations.$country.tsx
export const loader = async ({ params }: LoaderFunctionArgs) => {
  const country = (params.country || "").toLowerCase().trim();
  
  if (country === "france") {
    return redirect("/destinations/study-in-france", 301);
  }
  if (country === "new-zealand") {
    return redirect("/destinations/study-in-new-zealand", 301);
  }
  if (country === "hungary") {
    return redirect("/destinations/study-in-hungary", 301);
  }
  
  return null;
};

3. Visual & Aesthetic Standards (Ultra-Premium Only)

Plain, unstyled black-and-white text pages are completely prohibited. All destination pages must reuse the Study Prime design system (app/styles/destination-landing.css):

A. Dark Luxury Hero Section

  • Theme: Deep Navy gradient (#011E3E to #02162C).
  • Backdrop: High-resolution destination photo overlay (16% opacity, blur & radial vignette).
  • Eyebrow Badge: Gold/Orange pill badge (OFFICIAL STUDY DESTINATION GUIDE).
  • Trust Chips: Frosted glass badges ("No False Guarantees", "Official Visa Guidance").
  • Dual CTAs: Primary button in Gold/Orange (#FFA000) with Navy text (#011E3E), plus glass secondary button.
  • Showcase Floating Card (Right Column): Arched destination photo, country flag, key facts pills, and direct assessment booking button.

B. Sticky Sub-Navigation Bar

  • Positioned below global header with backdrop-filter: blur(14px).
  • Quick anchor links: Suitability, Courses, Fees & Budget, Admissions, Visa, Scholarships, FAQs.

C. Card-Based Systems

  • 2-Column Comparison: Emerald border for "Worth Exploring", Amber border for "Pause and Review".
  • Step Timeline: Numbered steps (1 to 4) with dark navy circles and gold numerals.
  • Cost Cards: Structured cards for Tuition, Daily Living, and Immigration Funding Minimums.
  • SSR FAQs: Semantic <details> and <summary> tags for 100% crawlable server-rendered FAQ text.
  • Mobile Floating CTA Bar: Safe-area compliant bar fixed at the bottom of mobile screens.

4. SEO, Sitemap & Funnel Integration

  • Sitemap (app/routes/[sitemap.xml].ts): Add /destinations/study-in-[country] to dedicatedDestinations and filter out the old slug from generic routes.
  • Internal Links: Update Header dropdowns, Footer links, and DestinationsSection.tsx carousel cards to the new URL.
  • JSON-LD Schema: Include Service, BreadcrumbList, and FAQPage schemas in initial HTML.
  • Assessment Integration: Primary CTAs link to /assessment?destination=[country], and assessment.tsx must automatically pre-populate the selected country.

5. Git & Deployment Safety

Safety Protocols:
  • NEVER run git push without explicit confirmation from the repository owner.
  • Always verify npm.cmd run typecheck passes with exit code 0.
  • Test direct loads, mobile responsiveness, and redirects locally at http://localhost:3000.
